# Термины домена

Единый словарь: эти имена используются в коде, API и интерфейсе.
Код — на английском, интерфейс — на русском.

| Русский | English (код) | Значение |
|---|---|---|
| Рабочее пространство | workspace | Верхний контейнер: команда или подразделение. Граница данных и прав |
| Проект | project | Набор связанных задач с общей целью. Срока нет; статус — активный или архивный (ADR-0005) |
| Задача | task | Единица работы: исполнитель, статус, срок |
| Доска | board | Канбан-представление задач проекта |
| Колонка | column | Стадия задачи на доске |
| Клиент | account | Компания-контрагент |
| Контакт | contact | Человек на стороне клиента |
| Сделка | deal | Потенциальная продажа: сумма, валюта, стадия |
| Стадия воронки | stage | Этап сделки в воронке |
| Воронка | pipeline | Упорядоченный набор стадий |
| Статус задачи | task status | Один из фиксированного набора: «К выполнению» (todo), «В работе» (in_progress), «На проверке» (review), «Готово» (done). Закрытая задача — в статусе «Готово». Колонки доски соответствуют статусам |
| Техадминистратор | tech admin | Роль: системные настройки, учётные записи, роли, журнал аудита. Доступа к бизнес-данным нет |
| Бизнес-администратор | business admin | Роль: проекты, участники, задачи в своих проектах, CRM |
| Смешанная роль (СМ) | mixed | Техадминистратор + бизнес-администратор (ТЗ §4, ADR-0003). При расхождении действует матрица ТЗ §4: например, удаляет любой проект, а не только свой. Задачи читает и меняет, любые комментарии удаляет в проектах, где участвует; своя задача в проекте для этого не нужна. Добавить себя может в любой проект. «СМ — в любом проекте» в правах на задачи читается как «в любом, где участвует» (ADR-0009) |
| Пользователь | user | Роль: свои задачи в проектах, где участвует; без доступа к CRM |
| Бизнес-пользователь | business user | Термин ТЗ §6 (п. 6, 7), не отдельная роль: = роль «Пользователь» (spec 001, OI-43) |
| Менеджер | manager | Термин ТЗ §6 (п. 8), не отдельная роль: бизнес-администратор или смешанная роль (spec 001, OI-41) |
| Своя задача | own task | Задача, которую сотрудник создал для себя: он и автор, и исполнитель. Менять исполнителя может только БА (и СМ) |
| Свой проект | own project | Для правки чужих задач — проект, где сотрудник владелец ИЛИ имеет неудалённую задачу как автор или исполнитель (ADR-0009). Удалить проект может только его владелец (СМ — любой) |
| Метка | label | Общая для рабочего пространства пометка задачи: одна метка доступна во всех проектах. Создают, переименовывают и удаляют БА и СМ; «Пользователь» только назначает существующие метки на свои задачи. На задаче не больше 10 меток (spec 001, FR-18b) |
| R1 / MVP / пилот | R1 / MVP / pilot | Синонимы: один и тот же объём — ТЗ §2 (`docs/brief/vision.md`). `docs/mvp.md` — черновик и при расхождении уступает ТЗ и spec (spec 001, OI-44, ADR-0008) |
| Цель | objective | Цель команды (бэклог) |
| Ключевой результат | key result | Измеримый результат цели (бэклог) |
