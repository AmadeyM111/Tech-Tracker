# Подключение AI-агентов через MCP

Трекер отдаёт задачи, проекты и комментарии по протоколу MCP (Model Context Protocol). Так можно
работать с трекером из кодового агента (Claude Code, Codex CLI, Cursor и других) — не переключаясь в
веб-интерфейс. Решения зафиксированы в `docs/adr/0018-mcp-agent-access.md`.

## Что важно знать

- **Агент действует от вашего имени** и видит и меняет только то, что разрешено вашей роли. Правила
  прав те же, что в веб-интерфейсе: например, «Пользователь» не может назначить задачу другому.
- **Токен — секрет.** Он показывается один раз при создании. В трекере хранится только его хеш.
- **Срок жизни — 90 дней.** Можно иметь не больше 10 активных токенов одновременно.
- **Блокировка учётной записи отзывает все её токены.**
- **Действия агента видны в ленте проекта** с именем токена: например, «Claude Code на ноутбуке».
- **Облачные клиенты не поддерживаются в R1.** ChatGPT и другие сервисы, которые подключаются к
  серверу из интернета, не могут достучаться до localhost-пилота. Поддержка потребует отдельного
  решения (ADR), которое изменит это ограничение; текущее решение — ADR-0018.

## 1. Создайте токен

1. Войдите в трекер и откройте раздел **«Доступ для агентов»**.
2. Введите понятное имя, например `Claude Code на ноутбуке`.
3. Нажмите «Создать» и **сразу скопируйте токен** (начинается с `gtrk_`). Второй раз он не покажется.
4. Чтобы отключить агента, отзовите токен в том же разделе.

Токен передаётся в переменной окружения `GTRACK_TOKEN`. Не вставляйте его в репозиторий и в
общие файлы конфигурации.

## 2. Подключите агента

Адрес MCP-эндпоинта — `https://<хост>/mcp` (по умолчанию `https://localhost/mcp`). Для
самоподписанного сертификата пилота см. раздел «Сертификат» ниже.

### Claude Code

Вариант A — HTTP (агент подключается по адресу, токен в заголовке):

```bash
claude mcp add --transport http gtrack https://localhost/mcp \
  --header "Authorization: Bearer $GTRACK_TOKEN"
```

Вариант B — stdio (агент запускает мост `gostracker mcp`; нужен установленный пакет трекера):

```bash
claude mcp add gtrack -e GTRACK_TOKEN=$GTRACK_TOKEN -e GTRACK_URL=https://localhost \
  -- gostracker mcp
```

Команда `claude mcp add` сохраняет значение переменной в конфигурации Claude Code. Используйте
вариант B, если хотите, чтобы токен не попадал в URL и заголовки; в обоих случаях он хранится на
вашей машине в пользовательской конфигурации.

### Codex CLI

Вариант A — HTTP, токен берётся из переменной окружения:

```bash
codex mcp add gtrack --url https://localhost/mcp --bearer-token-env-var GTRACK_TOKEN
```

Вариант B — stdio:

```bash
codex mcp add gtrack --env GTRACK_TOKEN=$GTRACK_TOKEN --env GTRACK_URL=https://localhost \
  -- gostracker mcp
```

### Мост `gostracker mcp`

Подкоманда читает настройки из окружения и не принимает токен аргументом командной строки:

| Переменная | Обязательна | Значение по умолчанию | Назначение |
|---|---|---|---|
| `GTRACK_TOKEN` | да | — | токен агента (`gtrk_…`) |
| `GTRACK_URL` | нет | `https://localhost:<HTTPS_PORT>` | адрес трекера без пути `/mcp` |
| `GTRACK_CA_FILE` | нет | — | файл сертификата для самоподписанного TLS |
| `HTTPS_PORT` | нет | `443` | порт, если `GTRACK_URL` не задан |

Без `GTRACK_TOKEN` мост завершается с кодом 2 и подсказкой. Сообщения об ошибках идут в stderr.

## 3. Инструменты

| Инструмент | Что делает |
|---|---|
| `list_my_tasks` | мои задачи и подзадачи (я исполнитель), по сроку |
| `list_project_tasks` | задачи проекта; фильтры по исполнителю и статусу |
| `get_task` | карточка задачи с подзадачами и правами |
| `create_task` | создать задачу в проекте |
| `create_subtask` | создать подзадачу у задачи верхнего уровня |
| `update_task` | изменить поля задачи; передавайте только меняемые поля |
| `list_projects` | проекты: БА видит все, остальные — где они участники |
| `get_project` | карточка проекта |
| `list_comments` | комментарии задачи |
| `add_comment` | добавить комментарий к задаче |

Удаление задач и проектов, участники, роли, учётные записи и CRM через MCP в R1 не открыты.

## 4. Сертификат

Поставляемая конфигурация принимает подключения только по HTTPS. Если сертификат самоподписанный:

- для моста `gostracker mcp` укажите `GTRACK_CA_FILE=/путь/к/сертификату.pem`;
- для Claude Code по HTTP (Node.js) укажите `NODE_EXTRA_CA_CERTS=/путь/к/сертификату.pem` в окружении
  запуска агента.

## 5. Диагностика

- **401 `not_authenticated`** — токен неверный, отозван, истёк, или учётная запись заблокирована.
  Создайте новый токен.
- **403 `password_change_required`** — сначала смените одноразовый пароль в веб-интерфейсе.
- **403 `no_role`** — администратор ещё не назначил вам роль.
- **409 `token_limit_reached`** — отзовите неиспользуемые токены (лимит — 10).
- **403 `origin_mismatch`** — запрос с чужим заголовком `Origin`; MCP-клиенты его не отправляют.
