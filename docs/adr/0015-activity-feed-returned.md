# ADR-0015. Лента проекта возвращена в текущую версию (частичная отмена SC-8 из ADR-0012)

- **Дата:** 2026-11-03
- **Статус:** принято (решение владельца, 2026-11-03)
- **Уточняет:** ADR-0012 в части SC-8 (лента проекта «не нужна для демо»; D-55)
- **Связано:** `specs/001-pilot-r1/spec.md` v0.21 (FR-38 в объёме проекта, UF-9, AC-90);
  `specs/001-pilot-r1/plan.md` §4.4, §10.3, §10.5; `specs/001-pilot-r1/tasks.md` (T104; T55 и T65
  переведены в SUPERSEDED/SKIPPED с отсылкой к T104)

## Контекст
ADR-0012 отложил ленту активности проекта (SC-8) и поиск (SC-9) в следующую версию. В MVP-пересборке
журнал событий продолжал писать события аудита, а события ленты (`project.updated`, `member.*`,
`task.*`, `comment.*`) не писались (D-55). Владелец решил вернуть ленту проекта в текущую версию
пилота, чтобы участники видели, что происходит в проекте.

## Решение
- **В текущую версию возвращается лента проекта:** FR-38 в объёме проекта, UF-9 и AC-90 (проектная
  часть). Реализация — задача T104 в `specs/001-pilot-r1/tasks.md`.
- **Объём событий ленты** — по таблице plan §10.5 для типов, доступных в MVP: `project.updated`,
  `member.added`, `member.removed`, `task.created`, `task.updated`, `task.deleted`,
  `task.unassigned_member_removed`, `comment.created`, `comment.deleted`. Вложения (`attachment.*`)
  остаются вне MVP, потому что вложения отложены (T49–T51).
- **Права:** лента видна только участникам проекта (403 не участнику, D-45). Значения полей в ленте
  не отдаются для названия и описания (Q-5), текст комментариев в ленте не отдаётся.
- **Не возвращается:** лента сделки (SC-1, CRM вне MVP) и поиск (SC-9). Остаются отложенными
  по ADR-0012.

## Последствия
- Тесты, которые фиксировали отсутствие событий ленты (D-55), обновлены на ожидаемые события:
  проверки `events == []` заменены на список действий. Тесты не удалены и не ослаблены.
- Сервисы участников, проектов, задач и комментариев пишут события через `record_event` в той же
  транзакции (AC-67: откат изменения откатывает и событие).
- Миграций схемы не требуется: таблица `domain_event` уже содержит `project_id`, `changes` и
  индекс по проекту (миграция 0002).
