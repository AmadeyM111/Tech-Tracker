# ADR-0030. Inbox MCP и список застрявшей работы

- **Дата:** 2026-11-16
- **Статус:** предложено (спека 034, CD-02 / CD-04)

## Решение
Внешние сообщения (старт — Telegram) входят через MCP `ingest_message`, а не через бота
трекера. Идемпотентность держит таблица `external_message` (ключ workspace + source +
external_id). Без `task_id` создаётся задача; с `task_id` — комментарий, статус не меняется.

`list_stuck_work` — read-only: не `done` в проектах актора, нет движения 48 часов.
Просрочка — отдельное поле. `blocked` / `open_dod` — `null`, пока нет колонок 0019.

## Причины
- Агент уже в чате; свой Telegram-бот вне рамок.
- «Горит» и галка статуса — другие сессии (CD-01/03). ПМ нужен список без движения.

## Альтернативы и почему отвергнуты
- **Колонки источника на `task`.** Отвергнуто: конфликт с миграцией 0019 (DoD/блокер).
- **Веб-бот Telegram.** Отвергнуто брифом.
- **Только просрочка как критерий stuck.** Отвергнуто кастдевом: галка ≠ сделано, срок —
  не единственный сигнал.

## Последствия
- Миграция `0020` аддитивна, `down_revision=0018`. Выкатка с `ALLOW_MIGRATIONS=1`.
- Две головы alembic, пока 0019 не слита: 0020 и 0019 обе от 0018; сводит оркестратор.
