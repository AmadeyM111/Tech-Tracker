# ADR-0023. Выгрузка выборки «Сводки» в CSV: право, формат, предел, аудит

- **Дата:** 2026-11-10
- **Статус:** принято (владелец, 2026-11-10; спека 025)

## Решение
Выгрузка выборки «Сводки» — `GET /api/v1/me/overview/tasks.csv`, только для роли «бизнес-администратор» (новая возможность
`export_overview`). Формат: UTF-8 с BOM, разделитель `;`, CRLF, текстовые поля в кавычках, русские подписи статусов и
приоритетов, даты `ДД.ММ.ГГГГ` по Москве. Ячейки, начинающиеся с `=`, `+`, `-`, `@`, табуляции или `\r`, выводятся с ведущим
апострофом. Предел — `CSV_MAX_ROWS` (10 000 по умолчанию): при превышении отказ 422 `export_too_large`, без усечения. Каждая
успешная выгрузка пишет событие журнала аудита `user.overview_exported` (автор, время, число строк строкой в `details.rows`;
значения фильтров и содержимое не пишутся, BR-2).

## Причины
Файл выносит данные из системы, поэтому нужны отдельное право, запись в журнале и защита от CSV-инъекций (формулы в названиях
задач, которые вводит любой участник проекта). BOM и `;` — требование Excel с русской локалью (T-03 F4). Усечённый отчёт хуже отказа:
читатель не узнает, что строк не хватает.

## Альтернативы и почему отвергнуты
- Право по `business_access` (получил бы и Пользователь) — противоречит решению владельца 2026-11-08 (CSV только БА).
- Усечение до лимита с предупреждением — неполный отчёт без явного признака в самом файле.
- Не экранировать формулы — рекомендация OWASP против; риск исполнения формул в Excel у получателя.
- Отдельная сущность аудита (`export`) — потребовала бы изменений каталога и вывода журнала; сущность «пользователь-автор» уже поддержана.
- Потоковая выдача без лимита — нагрузка на память и БД без пользы для пилота.

## Последствия
Новая возможность в `ROLE_CAPABILITIES` и в `GET /me`; новый ключ `rows` в допустимых деталях событий пользователя
(`UserEventDetails`); новое действие журнала и его русское название; конфиг `CSV_MAX_ROWS`; тест матрицы ролей. Для любой следующей
выгрузки данных наружу применяется тот же набор: отдельное право, предел, защита формул, запись в аудит.
