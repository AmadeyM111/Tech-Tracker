# ADR-0029. DoD на задаче и блокер отдельно от «Горит»

- **Дата:** 2026-11-16
- **Статус:** предложено
- **Спека:** 033

## Решение
Критерии готовности хранятся строками `task_dod_criterion` у задачи. Статус `done`
ставится только если нет открытых обязательных критериев. Агент MCP при флаге
`human_close_only` (по умолчанию включён) не ставит `done`. Блокер — поля `task.blocked*`
и метка «Блокер»; правило «Горит» спеки 008 не меняется.

## Причины
Кастдев ПМ 2026-11-16: галка статуса врёт, нейронки не выводят готовность, «горит» —
инцидент, не просрочка. Подзадачи уже есть и не заменяют явный перечень «готово, когда».

## Альтернативы и почему отвергнуты
- Считать родителя готовым по подзадачам — ПМ просит явные критерии, не прогресс детей.
- Заменить `hot` на `blocked` — ломает 008 AC-8.
- Шаблон DoD у проекта в этом срезе — отложен: критерии задают на задаче.

## Последствия
Миграция 0019. Автодеплой на миграции останавливается: выкатка с `ALLOW_MIGRATIONS=1`.
Новые коды: `dod_open` (422), `human_close_only` (403), `task_blocked` (422),
`task_already_done` (422).
