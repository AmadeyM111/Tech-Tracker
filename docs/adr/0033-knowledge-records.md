# ADR-0033. Слои знаний: `knowledge_record` выше проекта

- **Дата:** 2026-11-18
- **Статус:** предложено (спека 037, CD-08 + CD-09)

## Решение
Знания живут в таблице `knowledge_record` со слоем `scope=space|project`.
Слой пространства виден участникам любого проекта пространства. Project-слой
виден только участникам этого проекта. Типы записи: `decision`, `reason`,
`agreement`. MCP: `list_knowledge`, `get_knowledge`, `upsert_knowledge`.
Без `commit=true` строк в таблице нет. Пересказ без типа и полей — 422
`knowledge_unstructured`. Миграция **0021**, `down_revision=0018` (0019 и 0020
заняты соседними сессиями).

## Причины
- Кастдев: урок умирает вместе с проектом, если нет слоя выше.
- Запись «можно опереться» — решение / причина / договорённость, не свалка vault.
- Commit как у `propose_entities` (CD-06): агент предлагает, человек подтверждает.

## Альтернативы и почему отвергнуты
- **Viking / векторный поиск / wiki.** Вне рамок кастдева.
- **Колонки на `task` / `project`.** Смешивает трекер и базу знаний; ALTER `task`
  занят соседними сессиями.
- **Событие в каталоге §10.5.** Каталог заперт тестом T30; `client_name` храним
  на строке записи.

## Последствия
- Alembic-голова этой ветки — 0021 с разрывом 0019/0020; слияние с DoD/inbox —
  оркестратор.
- UI карточки знания в этом срезе нет.
