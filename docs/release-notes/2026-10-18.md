# GOSTracker: релиз-ноты за 18.10.2026

Ветка `feat/r1.0-foundation`. Изменения только в интерфейсе. Бэкенд и API-контракт не менялись, новых зависимостей нет.

## Что нового для пользователей

**Старт сразу в «Проекты»**
- Страницы «Главная» больше нет, ссылки «На главную» тоже.
- После входа и после смены пароля:
  - Бизнес-админ и Пользователь попадают в «Проекты».
  - Тех-админ попадает в «Учётные записи».
  - Пользователь без роли остаётся на экране «Роль не назначена».
- На заголовке стартового экрана виден фокус, это удобно при работе с клавиатуры.
- Неизвестные адреса ведут туда же.

**Боковое меню на всех экранах**
- Меню есть и у Тех-админа (в том числе на «Журнале аудита»), и на экранах «нет прав».
- «Выйти» теперь внизу меню на всех экранах.
- У меню есть имя «Меню» для экранных дикторов.

**Новая кнопка «Задача» в боковом меню**
- Светлая таблетка «+ Задача» 160 px. Она видна Бизнес-админу и Пользователю.
- Открывает окно «Новая задача»: выбор проекта и название.
  - В списке только проекты, где вам можно создавать задачи.
  - На странице проекта он выбран заранее. Если доступен один, выбирается он.
  - Если таких проектов нет, окно скажет об этом.
- После создания открывается карточка задачи. Доска и список задач обновляются сразу, без ожидания опроса.
- Ошибки (нет прав, проект не найден, сервер занят, нет сети) показываются в окне, введённое сохраняется.
- Окно закрывается по Escape и «Отмена». Пока идёт запрос, закрыть его нельзя. Повторное нажатие не создаёт дубликат.

**На Доске убрана кнопка «Добавить задачу»**
- Создавать задачи теперь можно из меню и из вкладки «Задачи» проекта.
- Перетаскивание, фильтр по исполнителю и опрос работают как раньше.

**Справка на экране входа**
- Под формой появился блок «О системе»: что это за продукт и что учётную запись и первый пароль выдаёт технический администратор.

**Вид**
- Подписи ролей: «Тех-админ», «Бизнес-админ».
- Колонка контента стала шире (100rem), в «Учётных записях» слова в колонках «Роль» и «Состояние» не переносятся.

- **Спецификации:**
  - 003 «Без Главной» (11 задач), принята с замечаниями.
  - 004 «Задача в меню, без создания на Доске» (10 задач), принята с замечаниями.
  - 005 «Справка на входе», одобрена.
  - Spec 001 обновлена до v0.19 со ссылками на эти дельты.
- **Основные файлы:** `frontend/src/app/router.tsx` (стартовый экран, `Sidebar`), `frontend/src/features/tasks/CreateTaskForm.tsx` (окно), `frontend/src/features/auth/session.ts` (фокус), `frontend/src/features/projects/api.ts` (доступные проекты).
- **Удалено:** `Home`/`Root`, ссылка «На главную», иконка `home`, создание из колонок Доски, шесть ключей `boards.*` и три правила стилей.
- **Кэш профиля** (`useSession`) живёт 5 секунд. Безопасность держится на очистке кэша при входе, выходе, смене пароля и ответе 401 (plan 003, решение D-12).
- **Тесты:** frontend 1199 из 1199, lint и typecheck чистые, тесты документов и каркаса 290 из 290. Каждый тест удалённого поведения заменён или удалён по spec.
- **Не запускались:** `bash scripts/check.sh` и полный backend-pytest (бэкенд не тронут).

## Известные ограничения
- После щелчка по фону окна Shift+Tab в Chromium может вывести фокус за окно, так же устроено окно смены пароля. Критерии приёмки выполнены.
- При возврате «Назад» на «Учётные записи» фокус снова встаёт на заголовок.
- На `/login` при живой сессии форма входа видна, пока идёт проверка сессии.
- Роль «Смешанная» исчезнет из списка ролей только после обновления api по ADR-0013 (вместе с миграцией 0006).
