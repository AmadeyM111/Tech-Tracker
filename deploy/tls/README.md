# TLS-сертификат

Веб-сервер (`web`) принимает соединения только по HTTPS; порт 80 лишь переадресует на HTTPS.

## Самоподписанный сертификат (по умолчанию)

Если сертификат не положен, при первом запуске `web` сам создаёт самоподписанный сертификат
(EC prime256v1, 825 дней) для имени из `TLS_SERVER_NAME` (а также `localhost` и `127.0.0.1`) и
сохраняет его в томе `tls-generated`. При перезапусках и пересоздании контейнера сертификат
не меняется. Браузер покажет предупреждение о недоверенном сертификате.

## Свой сертификат

Положите в этот каталог два файла:

- `tls.crt` - сертификат (при необходимости с цепочкой промежуточных);
- `tls.key` - закрытый ключ без пароля.

Каталог монтируется в контейнер только на чтение (`./deploy/tls:/etc/gostracker/tls:ro`).
Если оба файла есть, они используются вместо самоподписанного. После замены перезапустите `web`:
`docker compose restart web`.

## Безопасность

Файлы `*.crt` и `*.key` из этого каталога не коммитятся в git (они перечислены в `.gitignore`)
и не попадают в образы: образ `web` собирается без каталога `deploy/tls`.
