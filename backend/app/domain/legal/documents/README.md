# Тексты Политики и Согласия (спека 021)

- `privacy.json`, `consent.json` — тексты; `requisites.json` — реквизиты оператора (единственное место). В текстах
  подстановки `{operator_name}`, `{operator_ogrn}`, `{operator_inn}`, `{contact_email}`, `{site_url}`; почтовый адрес
  (`operator_postal_address`) необязателен и в тексте только если задан.
- `version` в обоих файлах — одна дата `ГГГГ-ММ-ДД`. Изменили текст — меняйте дату в обоих файлах: пользователи
  подтвердят согласие заново (гейт `pdn_consent_pending`).
- Страницы `/privacy`, `/consent` и экран `/pdn-consent` доступны только при `PDN_CONSENT_ENABLED=true`; при выключенном флаге
  API отвечает 404, а фронт ведёт на `/login`.

## Пометки «[предложение, подтвердить у юриста]»
Стоят в абзацах, которые не подтвердил юрист (действия с данными, срок хранения, отзыв, передача почтовому сервису, реквизиты
для обращений). Пока флаг выключен, пользователи текстов не видят.

Как снять (после подтверждения юриста и по команде владельца):
1. Найти: `grep -n "предложение, подтвердить" backend/app/domain/legal/documents/*.json`.
2. В каждом найденном абзаце удалить пометку вместе с пробелом перед ней; при правке формулировки по замечаниям юриста обновить
   и `version`.
3. Проверить: `python scripts/check_legal_requisites.py` — предупреждение о пометках пропадает (на код возврата оно не влияет).
4. Только после этого включать `PDN_CONSENT_ENABLED=true` в production.
