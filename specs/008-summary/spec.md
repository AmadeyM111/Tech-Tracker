# Spec: «Сводка» — плитки, «Нужно проверить», приоритет и срок (короткая)

- **ID:** 008-summary
- **Статус:** DRAFT (короткая версия; открытые вопросы — §8)
- **Дата:** 2026-11-08
- **Пакет:** R2 T-03 «Сводка без CSV». Полной спеки 008 нет: решение владельца 2026-11-08 («Q-7») — короткая спека только на F1a–F1d.
  Основание: решения владельца 2026-11-08 (D-3; Q-13, Q-14, Q-15 задачного списка, `r2-dev-task-list.md`); ADR-0006, ADR-0007, ADR-0012, ADR-0013.
  Макет `Shared/Design/summary-r2-design.md` — визуальный ориентир; соответствие макета этой спеке не проверялось. P-S1 открыт (Q-9).

## 1. Контекст и цель
В R1 нет общего списка задач по всем проектам и фильтра по сроку (001/FR-27a отложен, ADR-0012).
Участник пилота должен одним экраном видеть, сколько задач в каждом статусе, что ждёт его проверки,
что просрочено и что горит. Спека закрывает F1a–F1d экрана «Сводка».

Вне пакета: CSV-выгрузка, диапазон дат, карточка «Подключить ИИ-агента», фильтр по исполнителю (§7).

## 2. Пользовательские сценарии
- Как участник, я хочу видеть число задач по статусам во всех моих проектах, чтобы понимать объём работы.
- Как автор задачи или владелец проекта, я хочу видеть задачи, которые ждут моей проверки.
- Как участник, я хочу отфильтровать список по приоритету и сроку, чтобы найти горящее.
- Как участник без задач, я хочу видеть нулевые плитки и понятный текст, а не пустой экран.

## 3. Термины
- **Мои проекты** — неудалённые проекты пространства, где пользователь владелец (`project.owner_id`)
  или участник (строка `project_member`), как у `can_read_project_content`.
- **Задачи сводки** — неудалённые задачи и подзадачи моих проектов (подзадачи наравне, Q-1 задачного
  списка — решено).
- **Выборка списка** — задачи сводки, прошедшие фильтры списка.
- **Сегодня** — `today_msk()` (ADR-0007), часовой пояс Europe/Moscow. Срок хранится как дата `YYYY-MM-DD`.

## 4. Функциональные требования
- **FR-1 (меню, экран):** Пункт «Сводка» в боковом меню и экран `/summary` ДОЛЖНЫ быть у пользователей
  с `business_access` (П и БА). У ТА их нет (ADR-0013).
- **FR-2 (F1a, плитки):** Экран ДОЛЖЕН показывать плитки «Всего», «Не начато» (`todo`), «В работе»
  (`in_progress`), «На проверке» (`review`), «Готово» (`done`) с числом задач сводки. Сумма четырёх
  статусов ДОЛЖНА равняться «Всего». Плитки не зависят от фильтров списка (Q-2 задачного списка — решено).
- **FR-3 (F1b, «Нужно проверить»):** Отдельная плитка ДОЛЖНА считать задачи сводки в статусе `review`,
  где пользователь — автор задачи (`created_by`) или владелец проекта (Q-13 задачного списка — решено
  2026-11-08). Исполнитель без этих ролей в плитку не попадает (Q-8 — открыто).
- **FR-4 (переход по плитке):** Нажатие на плитку ДОЛЖНО открывать список с соответствующим фильтром:
  плитка статуса — фильтр этого статуса; «Всего» — без фильтра статуса; «Нужно проверить» — фильтр
  `needs_review`.
- **FR-5 (F1c, приоритет и фильтры списка):** Список ДОЛЖЕН фильтроваться по приоритету `low`/`medium`/`high`
  (мультивыбор), по проекту (один из моих проектов) и по статусу (одно значение, Q-7 — открыто).
  Фильтры объединяются через «И».
- **FR-6 (F1d, срок):** Список ДОЛЖЕН давать пресеты срока по Europe/Moscow (Q-14 задачного списка — решено:
  пресеты в R2; один пресет за раз, Q-7 — открыто):
  - «Просрочено» — `due_date < сегодня`; задачи в `done` не входят (Q-3 задачного списка — решено);
  - «Сегодня» — `due_date = сегодня`;
  - «Завтра» — `due_date = сегодня + 1`;
  - «На этой неделе» — `сегодня ≤ due_date ≤ воскресенье` текущей недели (текст оставлен как был;
    вариант «пн–вс» — открыто, Q-4);
  - «Без срока» — `due_date IS NULL`.
  Включение задач в `done` для «Сегодня», «Завтра», «На этой неделе» — открыто (Q-14).
- **FR-7 («Горит», D-3):** Строка списка ДОЛЖНА нести метку «Горит», если приоритет `high`, срок
  сегодня или в прошлом (`due_date <= сегодня`) и статус не `done` (исключение `done` — из Q-3
  задачного списка; открыто, Q-18). Метка — текст, не только цвет.
- **FR-8 (список):** Экран ДОЛЖЕН показывать постраничный список выборки с колонками «Проект», «Задача»,
  «Статус», «Приоритет», «Исполнитель», «Срок» и метку «Горит». Порядок — по сроку по возрастанию,
  без срока — в конце, тай-брейкер — `id` (Q-6 задачного списка — решено). Строка открывает карточку задачи.
- **FR-9 (количество):** Над списком ДОЛЖНА быть строка «Показано N из M», где N — строк на текущей
  странице, M — число задач выборки (Q-5 задачного списка — решено).
- **FR-10 (пусто):** Если задач сводки нет, вместо списка ДОЛЖЕН показываться текст «Задач пока нет.
  Они появятся, когда вас добавят в проект или вы создадите задачу.»; плитки остаются с нулями.
- **FR-11 (права):** API сводки ДОЛЖНО отвечать 401 без сессии и 403 пользователю без `business_access`.
  Данные отдаются только по моим проектам. Фильтр по чужому, удалённому или проекту другого пространства
  ДОЛЖЕН давать 404 (тот же ответ, что у несуществующего проекта).
- **FR-12 (обновление):** Плитки и список ДОЛЖНЫ обновляться опросом раз в 15 с (`POLL_INTERVAL_MS`).

## 5. Нефункциональные требования
- **NFR-1 (производительность):** Запросы счётчиков и списка сводки — p95 ≤ 500 мс на 50 000 задач,
  стенд 3 vCPU / 6 ГБ (R2 NFR-09). Замер — в T-10 (спека 016), вне CI.
- **NFR-2 (изоляция):** каждый запрос фильтруется по `workspace_id` актора и членству.
- **NFR-3 (интерфейс):** строки — в `ru.ts`; клавиатура; пресеты — `aria-pressed`; контраст WCAG AA;
  360 px без горизонтальной прокрутки (макет).
- **NFR-4 (без внешних вызовов):** новых исходящих запросов нет.

## 6. Критерии приёмки
- **AC-1** (FR-2): Given участник двух проектов с задачами 2 `todo`, 1 `in_progress`, 1 `review`,
  1 `done` When `GET /me/overview` Then счётчики 2/1/1/1, «Всего» 5.
- **AC-2** (FR-2, видимость): Given задачи в проекте, где пользователь не участник, в удалённом проекте,
  мягко удалённые и в другом пространстве When `GET /me/overview` Then они не посчитаны.
- **AC-3** (FR-3): Given задачи в `review`: (а) я автор, (б) я владелец проекта, (в) я только
  участник-исполнитель When `GET /me/overview` Then «Нужно проверить» = 2.
- **AC-4** (FR-4): Given фильтр `needs_review=true` When `GET /me/overview/tasks` Then в списке ровно
  задачи (а) и (б) из AC-3.
- **AC-5** (FR-5): Given задачи всех приоритетов When `priority=low&priority=high` Then в списке нет `medium`.
- **AC-6** (FR-6, граница суток): Given часы 2026-11-09T20:59:59Z (23:59:59 МСК) и 21:00:00Z
  (00:00 МСК 10.11) When пресет «Сегодня» Then в первом случае — задачи со сроком 09.11, во втором — 10.11.
- **AC-7** (FR-6): Given сегодня 2026-11-08 (воскресенье); задачи со сроком 07.11, 08.11, 09.11, 16.11
  и без срока When каждый пресет Then: «Просрочено» — 07.11; «Сегодня» — 08.11; «Завтра» — 09.11;
  «На этой неделе» — только 08.11 (вариант по Q-4 открыт); «Без срока» — задача без срока.
  Отдельный кейс: сегодня понедельник — «На этой неделе» включает воскресенье той же недели.
- **AC-8** (FR-7): Given `high`+срок вчера, `high`+сегодня, `high`+завтра, `medium`+вчера, `high`+вчера
  в статусе `done` When список Then «Горит» только у первых двух.
- **AC-9** (FR-9): Given 7 задач под фильтром и `page_size=5` When страница 1 Then `total=7`, 5 строк.
- **AC-10** (FR-11): Given ТА When запросы сводки Then 403; без сессии — 401; `project_id` чужого
  проекта — 404.
- **AC-11** (FR-5, FR-6, валидация): Given `priority=urgent` или `due=someday` When запрос Then 422.
- **AC-12** (FR-10, FR-1): Given пользователь без задач When открыт `/summary` Then плитки с нулями и
  утверждённый текст пустого состояния; пункт «Сводка» в меню есть у БА и П, нет у ТА.
- **AC-13** (FR-4, UI): Given экран When нажата плитка «В работе» Then фильтр статуса = «В работе»
  и список обновился.
- **AC-14** (NFR-1): p95 ≤ 500 мс на 50 000 задач — проверяется в спеке 016 (T-10), вне CI.

## 7. Вне рамок
- CSV-выгрузка и аудит выгрузки — не входят в R2 (решение владельца 2026-11-08; T-03 = «Сводка без CSV»).
- Диапазон дат в фильтре по сроку — R3 (Q-14 задачного списка).
- Карточка «Подключить ИИ-агента» (T-13) — R3 (Q-15 задачного списка), отдельная спека, номер при старте.
- Фильтр по исполнителю — вне рамок, пока не решён Q-11 задачного списка.
- Метки (T-12), поиск, настраиваемый часовой пояс, сохранение фильтров между сеансами.
