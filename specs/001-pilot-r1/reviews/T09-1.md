# T09, попытка 1 — CHANGES_REQUESTED

Проверено: test_logging 25 passed; backend/tests 341 passed; check.sh зелёный; под реальным uvicorn одна трассировка на 500,
потоковый ответ не буферизуется, обрыв клиента ок; fail-closed работает.
Блокирующее:
1. DoS: квадратичный бэктрекинг `_TEXT_SECRET_RE` (logging.py:37-46,88,360): путь запроса 60 КБ из `token.`*10000 = 6.4 с в redact_text,
   под uvicorn параллельный /health ответил через 25.8 с. Убрать неограниченные `[\w.\-]*` вокруг ключевого слова; тест на время (~64 КБ < 50 мс).
2. Экранированные кавычки: `{"password": "ab\"S3cr"}` -> `{"password": "***"S3cr"}` (частичная утечка). Нужно `"(?:\\.|[^"\\])*"` и аналог для `'`.
3. pydantic.ValidationError: `input_value='S3cr3tPW!x'` на отдельной строке от ключа не маскируется — маскировать `input_value=...` до `, input_type=`.
4. DSN `scheme://user:pass@host` не маскируется (repr(Settings), database_url): `(\w[\w+.\-]*://[^:/@\s]*:)[^@\s]+@` -> `\1***@`.
Желательное: подавлять только дубль `uvicorn.error` («Exception in ASGI application»), не все записи с exc_info;
отбрасывать extra `color_message`; пары-кортежи `(key, value)`/ASGI-заголовки `[(b"cookie", b"...")]` маскировать;
configure_logging при импорте app.main vs программный uvicorn.run (dictConfig вернёт свои обработчики) — закрепить в D-31.
