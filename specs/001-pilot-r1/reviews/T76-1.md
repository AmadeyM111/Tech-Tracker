# T76 — ревью (попытка 1 CHANGES_REQUESTED, попытка 2 принята по дельте)

**Попытка 1.** Независимый скрипт (права чтения, удалённое, фильтры, пагинация 101/100, прогресс) — всё совпало;
число запросов get_task 5 при 1 и 200 подзадачах; EXPLAIN на 50 000 задач — нужные индексы; мутации 14 из 15. Блок.:
`permissions.create_subtask=True` в карточке подзадачи, а сервис отвечает 422 `subtask_depth_exceeded` (флаг «разрешено»
не совпадал с результатом; 21 расхождение в матрице флагов).
**Попытка 2.** Флаг False для подзадач; факты из одного чтения; `workspace_id` во всех SELECT; списки без description;
явная ошибка инварианта; строгий 403 для без роли. Матрица флагов ↔ сервисы — 0 расхождений; мутации по дельте
убиты 5 из 8 тестами репозитория (+2 тестами ревьюера; D3 эквивалентен). Время ревью ≈ 6 + 6 мин.
