# Spec: «Сводка» — выгрузка выборки в CSV (только БА)

- **ID:** 025-summary-csv-export
- **Статус:** DRAFT (только бумага; код не пишется до решения владельца о запуске R3)
- **Дата:** 2026-11-10
- **Пакет:** R3 (T-03 F4–F5, R2-2, R2-3; CSV из R2 перенесён в R3, 2026-11-08). Основание: `008-summary`, ADR-0013 (роли), ADR-0023 (формат, лимит, аудит — черновик). Макеты: `Shared/Design/gtrack-r3/` (`csv-ba`, `csv-loading`, `csv-hidden`), тексты — предложения.

## 1. Контекст и цель
Бизнес-администратор хочет открыть выборку «Сводки» в Excel: отчёт руководителю, сверка с планом. Кнопка «Скачать CSV»
отдаёт текущую выборку с фильтрами файлом, который Excel с русской локалью открывает без настроек. Файл — это данные
из системы наружу: нужны право только у БА, защита от «формул» в ячейках, предел размера и запись в журнал аудита.

## 2. Пользовательские сценарии
- Как БА, я нажимаю «Скачать CSV» и получаю файл по текущим фильтрам, чтобы отправить отчёт.
- Как БА, я вижу понятное сообщение, если выборка слишком велика, и сужаю фильтры.
- Как Пользователь или ТА, я не вижу кнопки, а прямой запрос к API получает отказ.
- Как ТА, я вижу в журнале аудита, кто и когда выгружал данные.

## 3. Функциональные требования
- **FR-1 (эндпоинт):** `GET /api/v1/me/overview/tasks.csv` ДОЛЖЕН принимать те же фильтры, что `/me/overview/tasks`
  (`project_id`, `status`, `priority`, `due`, `due_from`/`due_to` после спеки 024, `needs_review`), без `page`/`page_size`,
  и отдавать ВСЕ задачи выборки (не только текущую страницу), в порядке списка («Сводка» FR-5).
- **FR-2 (право):** выгрузка доступна только роли «бизнес-администратор»: новая возможность `export_overview`
  (в `capabilities` ответа `GET /me`). Пользователь и ТА получают 403 `forbidden`; без сессии — 401. Кнопка видна только при наличии возможности.
- **FR-3 (формат, T-03 F4):** UTF-8 с BOM, разделитель `;`, перевод строки CRLF, все текстовые поля в кавычках, кавычка внутри
  удваивается. Колонки: Проект, Задача, Статус, Приоритет, Исполнитель, Срок, Создана, Изменена, Ссылка. Значения читаемые:
  статус и приоритет — русскими подписями интерфейса, «Срок» — `ДД.ММ.ГГГГ` (пусто, если срока нет), «Создана»/«Изменена» —
  `ДД.ММ.ГГГГ ЧЧ:ММ` по Москве, исполнитель — логин (пусто, если нет), «Ссылка» — `PUBLIC_BASE_URL/tasks/<id>` (Q-6).
- **FR-4 (формулы):** ячейка, текст которой начинается с `=`, `+`, `-`, `@`, табуляции или возврата каретки, ДОЛЖНА выводиться
  с ведущим апострофом `'` (защита от формул Excel; ADR-0023). Применяется ко всем текстовым колонкам; ссылка формируется системой и не экранируется.
- **FR-5 (состав, T-03 F5):** в файл попадают только задачи, которые пользователь видит на экране «Сводки» (то же членство,
  удалённые и чужие исключены), подзадачи наравне с задачами (008/Q-1).
- **FR-6 (лимит):** выборка больше `CSV_MAX_ROWS` (по умолчанию 10 000, конфиг) НЕ усекается молча: API отвечает 422
  `export_too_large` с текстом «В выборке N задач, максимум 10 000. Сузьте фильтры» (Q-1).
- **FR-7 (заголовки ответа):** `Content-Type: text/csv; charset=utf-8`, `Content-Disposition: attachment; filename="gtrack-summary-<YYYYMMDD-HHMM>.csv"`
  (время МСК), `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`.
- **FR-8 (аудит):** каждая успешная выгрузка ДОЛЖНА писать событие журнала аудита (кто, когда, число строк; значения фильтров и
  содержимое файла не пишутся, BR-2). Отказы (403, 422) событий не пишут. Событие видно ТА в «Журнале аудита» с русским названием.
- **FR-9 (интерфейс):** справа от строки «Показано N из M» — вторичная кнопка «Скачать CSV» (44 px); под ней подпись
  «В файл попадают задачи из текущей выборки с фильтрами» (Q-4). При загрузке: кнопка `disabled`, значок и текст «Готовим файл…»
  (`role="status"`); при ошибке — сообщение об ошибке через `ErrorAlert`, кнопка снова доступна. Файл сохраняется браузером.
- **FR-10 (пусто):** при пустой выборке кнопка доступна и отдаёт файл только с заголовками (Q-7).

## 4. Нефункциональные требования
- **NFR-1:** до 10 000 строк: p95 ≤ 3 с на стенде пилота; память — одна выборка (≈ единицы МБ), без постраничного опроса БД.
- **NFR-2:** изоляция по `workspace_id` и членству — как у списка; один SQL-запрос под снимок данных.
- **NFR-3:** CSV открывается в Excel (русская локаль) без настроек: кириллица, `;`, даты не превращаются в числа (формат `ДД.ММ.ГГГГ` — текст; Q-3).
- **NFR-4:** строки интерфейса — в `ru.ts`; клавиатура; контраст WCAG AA; 360 px без горизонтальной прокрутки (макет).
- **NFR-5 (безопасность):** защита от CSV-инъекций (FR-4); файл не кэшируется (FR-7); исходящих запросов нет.

## 5. Критерии приёмки
- **AC-1** (FR-1, FR-5): Given выборка из 120 задач (3 страницы по 50) When выгрузка Then в файле 120 строк данных и строка заголовков; порядок как в списке.
- **AC-2** (FR-1): Given фильтры `priority=high&status=review` When выгрузка Then в файле ровно задачи этих фильтров.
- **AC-3** (FR-2): Given Пользователь, ТА When запрос Then 403 `forbidden`; без сессии 401; БА — 200; `GET /me` БА содержит `export_overview`, у остальных нет.
- **AC-4** (FR-3): Given задачи с кириллицей, `;`, `"` и переводом строки в названии When выгрузка Then файл начинается с BOM `EF BB BF`, поля с `;`/`"`/переводом строки в кавычках, `"` удвоены, строки разделены CRLF; разбор стандартным `csv`-модулем (`delimiter=";"`) возвращает исходные значения.
- **AC-5** (FR-3): Given срок 2026-11-09 и изменение 2026-11-09T21:30Z When выгрузка Then «Срок» `09.11.2026`, «Изменена» `10.11.2026 00:30`.
- **AC-6** (FR-4): Given названия `=1+1`, `+1`, `-1`, `@SUM(A1)`, `\tx` When выгрузка Then ячейки начинаются с `'`; обычный текст без апострофа.
- **AC-7** (FR-5): Given чужой проект, удалённая задача, другое пространство When выгрузка Then их нет в файле.
- **AC-8** (FR-6): Given `CSV_MAX_ROWS=5` и выборка из 6 When выгрузка Then 422 `export_too_large`, файл не отдан, событие аудита не создано; при 5 — 200.
- **AC-9** (FR-7): Given успешная выгрузка Then заголовки ответа по FR-7; имя файла по времени МСК.
- **AC-10** (FR-8): Given успешная выгрузка When ТА открывает журнал Then есть запись с автором-БА и числом строк, без фильтров и содержимого; на 422/403 записей нет.
- **AC-11** (FR-9): Given БА на «Сводке» Then кнопка и подпись есть; Given Пользователь Then кнопки нет; Given клик Then `disabled` и «Готовим файл…» до ответа; Given 422 Then сообщение, кнопка доступна.
- **AC-12** (FR-10): Given пустая выборка When выгрузка Then файл только из заголовков.

## 6. Вне рамок
XLSX; выгрузка нескольких экранов; отправка по почте; фоновая выгрузка больших выборок; выбор колонок; выгрузка для Пользователя (отдельное решение владельца);
настраиваемый разделитель; сохранение выгрузок на сервере.

## 7. Допущения и зависимости
- Зависит от `008-summary`; параметры диапазона — от `024` (если 024 не в main, выгрузка без них).
- `PUBLIC_BASE_URL` задан на проде (используется письмами); если не задан — колонка «Ссылка» пустая (Q-6).
- Журнал аудита и его вывод — ADR-0006; новое действие и допустимые ключи деталей — ADR-0023.

## 8. Открытые вопросы владельцу
| # | Вопрос | Варианты | Рекомендация |
|---|--------|----------|--------------|
| Q-1 | Лимит строк: сколько и что делать при превышении? | 10 000 и отказ / усечение с предупреждением / без лимита | 10 000 и понятный отказ: усечённый отчёт вводит в заблуждение, а пилоту хватает с запасом (десятки проектов) |
| Q-2 | Язык и вид значений: «На проверке/Высокий» русскими подписями или коды (`review`/`high`)? | подписи / коды | Подписи (файл читают люди) |
| Q-3 | Формат дат: `ДД.ММ.ГГГГ` как текст или ISO `ГГГГ-ММ-ДД`? | `ДД.ММ.ГГГГ` / ISO | `ДД.ММ.ГГГГ`: привычнее; Excel с русской локалью распознаёт как дату |
| Q-4 | Подпись под кнопкой «В файл попадают задачи из текущей выборки с фильтрами» и поведение «все страницы, не только текущая» | подтвердить / другая формулировка | Подтвердить; добавить «все страницы» в тексте, если владелец хочет явности |
| Q-5 | Что писать в журнал аудита? | автор, время, число строк / плюс значения фильтров | Автор, время, число строк (значения фильтров могут содержать названия проектов; BR-2) |
| Q-6 | Колонка «Ссылка» — полный адрес (`https://…/tasks/<id>`)? Нужен `PUBLIC_BASE_URL` | да / относительная / без колонки | Полный адрес |
| Q-7 | Пустая выборка: отдавать файл с заголовками или блокировать кнопку? | файл / блок | Файл с заголовками (меньше особых случаев) |
| Q-8 | Только БА? Пользователь в R3 CSV не получает — подтвердить | да / и Пользователь | Только БА (решение 2026-11-08) |
| Q-9 | Защита от формул ведущим апострофом (`'=1+1`) приемлема? Название вида «-1 день» получит апостроф | апостроф / не экранировать | Апостроф (рекомендация OWASP; в Excel апостроф скрыт) |
| Q-10 | Текст «Готовим файл…» | подтвердить / заменить | Подтвердить |

## 9. Оценка
≈ 2,75 дня разработки + ревью (см. `tasks.md`); миграций нет (событие аудита — запись в существующую `domain_event`).
