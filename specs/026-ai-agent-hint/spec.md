# Spec: Карточка «Подключить ИИ-агента к GTrack» на «Сводке»

- **ID:** 026-ai-agent-hint
- **Статус:** DRAFT (только бумага; код не пишется до решения владельца о запуске R3)
- **Дата:** 2026-11-10
- **Пакет:** R3, T-13 (поправка к ТЗ, F1–F5). Основание: ADR-0018 (MCP-доступ агентов, токены в проде), `020-mcp-ai-native` (FR-10, инструкции), ADR-0022 (облачные клиенты — только R3, вне этой спеки), ADR-0024 (состояние подсказок — черновик). Макеты: `Shared/Design/gtrack-r3/` (`ai-card-shown`, `ai-card-closed`), тексты — предложения.

## 1. Контекст и цель
Токены для локальных ИИ-агентов (Claude Code, Codex CLI) уже работают, но пользователь о них узнаёт только из меню
«Доступ для агентов». Короткая закрываемая карточка вверху «Сводки» объясняет, что агент видит то же, что пользователь,
и ведёт к выпуску токена и к инструкции. Она не мешает работе и после закрытия не возвращается: состояние хранится
у пользователя в профиле, а не в браузере (T-13 F5), поэтому не «воскресает» на другом устройстве.

## 2. Пользовательские сценарии
- Как участник, я вижу карточку и по ссылке перехожу к выпуску токена или к инструкции.
- Как участник, я закрываю карточку одним касанием и больше её не вижу ни в этом, ни в другом браузере.
- Как участник, я могу вернуть карточку, если закрыл случайно (Q-2).

## 3. Функциональные требования
- **FR-1 (место):** карточка ДОЛЖНА выводиться в верхней части экрана «Сводка», над заголовком/плитками, только если
  подсказка не закрыта пользователем. Не блокирует работу, не модальная (Q-1: «Сводка» или профиль).
- **FR-2 (содержимое, T-13 F2–F4):** заголовок «Подключить ИИ-агента к GTrack»; текст «Агент увидит всё, что видите вы: свои
  проекты и задачи (формулировка о записи — Q-8). Чтобы подключить локального агента, выпустите токен в разделе «Доступ для агентов».»; ссылки
  «Доступ для агентов» (`/profile/agents`) и «Инструкция для Claude Code» (Q-3: куда ведёт). Облачные агенты (ChatGPT и
  подобные) не упоминаются (T-13 F3, ADR-0018 п. 5).
- **FR-3 (закрытие, T-13 F5):** кнопка «Скрыть» (44 px, вторичная) ДОЛЖНА убирать карточку сразу и сохранять закрытие на
  сервере в профиле пользователя; повторный показ — только по FR-6.
- **FR-4 (кому):** карточка видна пользователям с `business_access` (БА и Пользователь) — тем же, кому видна «Сводка».
  ТА «Сводку» не видит (ADR-0013) и карточку не получает.
- **FR-5 (API):** состояние подсказки ДОЛЖНО отдаваться в `GET /me` полем `dismissed_hints` (список ключей закрытых подсказок;
  сейчас допустим один ключ `ai_agent`). Закрытие — `POST /api/v1/me/hints/{key}/dismiss` (204, идемпотентно; неизвестный
  ключ — 404; без сессии — 401). Эндпоинт меняет только запись самого пользователя.
- **FR-6 (возврат, Q-2):** в «Профиле» ДОЛЖНА быть кнопка/ссылка «Показать подсказку про ИИ-агента снова», которая снимает
  закрытие (`DELETE /api/v1/me/hints/{key}/dismiss`, 204).
- **FR-7 (ошибка закрытия):** если сохранить закрытие не удалось, карточка остаётся/возвращается, показывается обычное
  сообщение об ошибке; пользователь может повторить.
- **FR-8 (доступность):** карточка — `<aside aria-labelledby=…>`; «Скрыть» с `aria-label` «Скрыть подсказку про ИИ-агента»;
  после закрытия фокус переходит на заголовок страницы; контраст AA; 360 px без горизонтальной прокрутки (макет).

## 4. Нефункциональные требования
- **NFR-1:** дополнительной загрузки экрана нет: поле приходит в уже запрашиваемом `GET /me`.
- **NFR-2 (безопасность):** карточка не раскрывает токенов и данных; ссылки внутренние (кроме инструкции, Q-3).
- **NFR-3:** строки в `ru.ts`; новых исходящих запросов нет.
- **NFR-4 (данные):** миграция аддитивная (таблица закрытых подсказок), откат — `drop table`.

## 5. Критерии приёмки
- **AC-1** (FR-1, FR-2): Given БА, подсказка не закрыта When открыта «Сводка» Then над плитками карточка с заголовком, текстом и двумя ссылками.
- **AC-2** (FR-3, FR-5): Given карточка When «Скрыть» Then карточка исчезает, `POST …/dismiss` → 204, `GET /me` содержит `dismissed_hints=["ai_agent"]`.
- **AC-3** (FR-3): Given закрытие When вход с другого браузера Then карточки нет.
- **AC-4** (FR-4): Given Пользователь Then карточка есть; Given ТА Then «Сводки» и карточки нет.
- **AC-5** (FR-5): Given неизвестный ключ When `POST /me/hints/foo/dismiss` Then 404; повтор закрытия `ai_agent` — 204 без ошибки; без сессии 401.
- **AC-6** (FR-6): Given закрытая подсказка When «Показать снова» в профиле Then `GET /me` без ключа и карточка снова на «Сводке».
- **AC-7** (FR-7): Given сбой сети/500 When «Скрыть» Then карточка остаётся, виден `alert`, повтор возможен.
- **AC-8** (FR-8): Given «Скрыть» с клавиатуры Then карточка закрыта и фокус на `h1`.
- **AC-9** (FR-2, ADR-0018): Given текст карточки Then в нём нет слов о ChatGPT/облачных агентах (проверка словаря).
- **AC-10** (NFR-4): Given БД на 0013 When `alembic upgrade head` и `downgrade 0013` Then цепочка проходит, таблицы нет после отката.

## 6. Вне рамок
Облачные агенты и шлюз (ADR-0022, T-14); другие подсказки (механизм позволяет, но в пакет входит одна); показ «один раз по времени»/счётчику показов;
встроенные ИИ-функции трекера (чат, автогенерация); хостинг документации (Q-3).

## 7. Допущения и зависимости
- Зависит от `008-summary` (экран) и `020-mcp-ai-native` / ADR-0018 (токены и «Доступ для агентов», в проде). Миграция `0014` (следующий свободный номер после `0013`; номер подтвердить по `docs/adr/REGISTRY.md` перед созданием).
- Текст инструкции для Claude Code уже есть в репозитории (`docs/ai-integration.md`); приложение документы не раздаёт — см. Q-3.
