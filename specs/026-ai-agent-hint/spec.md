# Spec: Карточка «Подключить ИИ-агента к GTrack» на «Сводке»

- **ID:** 026-ai-agent-hint
- **Статус:** APPROVED (решения владельца по §8 — 2026-11-10)
- **Дата:** 2026-11-10
- **Пакет:** R3, T-13 (поправка к ТЗ, F1–F5). Основание: ADR-0018 (MCP-доступ агентов, токены в проде, запись разрешена), `020-mcp-ai-native` (FR-10), ADR-0022 (облачные клиенты — вне этой спеки). Макеты: `Shared/Design/gtrack-r3/` (`ai-card-shown`, `ai-card-closed`).

## 1. Контекст и цель
Токены для локальных ИИ-агентов (Claude Code, Codex CLI) работают, но пользователь о них узнаёт только из меню «Доступ для агентов».
Короткая закрываемая карточка вверху «Сводки» объясняет, что агент действует от имени пользователя (видит и может менять то, что доступно
пользователю), и ведёт к выпуску токена и к инструкции. Закрытая карточка не возвращается в этом браузере.

## 2. Пользовательские сценарии
- Как участник, я вижу карточку и по ссылке перехожу к выпуску токена или к инструкции.
- Как участник, я закрываю карточку одним касанием и больше её не вижу в этом браузере.

## 3. Функциональные требования
- **FR-1 (место):** карточка ДОЛЖНА выводиться вверху экрана «Сводка», над заголовком и плитками, пока не закрыта. Не модальная, не блокирует работу.
- **FR-2 (содержимое):** заголовок «Подключить ИИ-агента к GTrack»; текст: «Агент увидит и сможет изменить всё, что доступно вам: свои проекты и
  задачи. Чтобы подключить локального агента, выпустите токен в разделе «Доступ для агентов».» (Q-8: слова о возможности изменять обязательны);
  ссылки «Доступ для агентов» (`/profile/agents`) и «Инструкция для Claude Code» (якорь на блок инструкции на этой же странице, FR-4). Облачные агенты
  (ChatGPT и подобные) не упоминаются (T-13 F3).
- **FR-3 (закрытие):** кнопка «Скрыть» (44 px, вторичная, `aria-label` «Скрыть подсказку про ИИ-агента») убирает карточку сразу и запоминает закрытие
  в браузере: `localStorage`, ключ `gtrack.hint.ai_agent.<id пользователя>` (Q-6). Возврата закрытой карточки нет (Q-2). Если `localStorage`
  недоступен (приватный режим, запрет), карточка просто показывается при каждом открытии и закрывается до перезагрузки страницы.
- **FR-4 (обновлено 2026-11-11):** блок «Инструкция для Claude Code» заменён простым блоком «Подключить ИИ-агента» на странице «Доступ для агентов» (якорь `#agent-connect`): после выпуска токена одно поле «Скопируйте и вставьте в своего ИИ-агента» с готовым текстом, переключатель «Claude Code / Другой клиент», кнопка «Скопировать», предупреждение «Токен виден только сейчас», «Подробнее» свёрнуто; адрес — `window.location.origin` + `/mcp`; токен только в состоянии страницы. Ссылки карточки ведут на `/profile/agents#agent-connect`.
- **FR-4 (исходная редакция, Q-3):** страница «Доступ для агентов» ДОЛЖНА содержать блок «Инструкция для Claude Code» с готовым фрагментом настройки (содержание —
  из `docs/ai-integration.md`, раздел Claude Code; конкретный URL и токен подставляются из страницы, секретов в тексте нет).
- **FR-5 (кому):** карточка видна пользователям с `business_access` (БА и Пользователь, Q-5), то есть тем, кому открыта «Сводка»; ТА «Сводку» не видит.
- **FR-6 (доступность):** `<aside aria-labelledby=…>`; после закрытия фокус переходит на заголовок страницы; контраст AA; 360 px без горизонтальной прокрутки.

## 4. Нефункциональные требования
- **NFR-1:** без новых запросов к API и без миграций; состояние — только в браузере (не переходит между устройствами и браузерами; принято владельцем).
- **NFR-2:** карточка не раскрывает токенов и данных; ссылки внутренние.
- **NFR-3:** строки в `ru.ts`; новых исходящих запросов нет.

## 5. Критерии приёмки
- **AC-1** (FR-1, FR-2): Given БА или Пользователь, карточка не закрыта When открыта «Сводка» Then над плитками карточка с заголовком, текстом и двумя ссылками; в тексте «увидит и сможет изменить».
- **AC-2** (FR-3): Given карточка When «Скрыть» Then она исчезает, в `localStorage` ключ с id пользователя; после перезагрузки страницы карточки нет.
- **AC-3** (FR-3): Given другой пользователь в том же браузере Then для него карточка показана (ключ по id пользователя).
- **AC-4** (FR-3): Given `localStorage` бросает исключение When «Скрыть» Then карточка закрыта без ошибки на экране.
- **AC-5** (FR-5): Given ТА Then «Сводки» и карточки нет.
- **AC-6** (FR-2): Given словарь `ru.ts` Then в тексте карточки нет слов о ChatGPT и облачных агентах.
- **AC-7** (FR-4): Given страница «Доступ для агентов» Then есть блок «Инструкция для Claude Code»; ссылка из карточки ведёт к нему.
- **AC-8** (FR-6): Given «Скрыть» с клавиатуры Then карточка закрыта и фокус на `h1`.

## 6. Вне рамок
Облачные агенты и шлюз (ADR-0022, T-14); возврат закрытой карточки (Q-2: не делаем); хранение закрытия на сервере и миграция `0014` (Q-6: не делаем);
другие подсказки; встроенные ИИ-функции трекера.

## 7. Допущения и зависимости
- Зависит от `008-summary` и от страницы «Доступ для агентов» (ADR-0018, в проде). Миграций и изменений API нет.
- Решение владельца: закрытие хранится в браузере, поэтому при смене браузера или очистке данных сайта карточка появится снова.

## 8. Решения по вопросам (владелец, 2026-11-10)
Q-1 на «Сводке»; Q-2 возврата закрытой карточки нет; Q-3 «Инструкция для Claude Code» — блок на странице «Доступ для агентов»; Q-4 подписи из макета;
Q-5 видят Пользователь и БА; Q-6 состояние «закрыто» в браузере (`localStorage`), без миграции `0014`; Q-7 текст из макета; Q-8 в тексте обязательно «увидит и сможет изменить» (токен даёт запись).

## 9. Оценка
≈ 1,25 дня разработки + ревью (см. `tasks.md`); без миграций и изменений API.
